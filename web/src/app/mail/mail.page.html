How zapply handles your mail

zapply reads each new inbox message's sender, subject and a short preview, and sends them to a language model to see whether they concern an application. Mail that does not is dropped on the spot: only its identifier is kept so it is never read twice. Mail that does is kept with its preview. Message bodies are never stored. Pause stops all reading and keeps the connection. Disconnect revokes zapply's access to the mailbox; the updates already found stay here. Connecting an address that is already here reconnects it.
